The de-identification contract

Identifiers never had a column to live in.

Subjects are pseudonyms from the first keystroke. Every date in the export becomes an integer offset from that recipient's transplant day, free text is dropped, and the chokepoint aborts the whole export if a single cell looks like a person's name.

{% comment %} The subject IDs below are deliberately un-real: a live ID is [S|D]CMV[R|D] plus two DIGITS, so "SCMVRxx" is shape-correct yet cannot collide with anyone on the register. A realistic-looking sample on an unauthenticated page is indistinguishable from an actual leak, both to a reader and to the test that guards this page. {% endcomment %}
